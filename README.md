# The Funniest AI Out-of-Office Reply

A tiny Python program that writes a single out-of-office reply in which the AI, left alone for the weekend, answers hundreds of emails, approves its own vacation, and is still on vacation. Run `python3 main.py` and it writes the entry, exactly as submitted, to `/output/entry.txt`.
